## 📱 نظرة عامة / Overview

**Super Fitness** هو تطبيق Flutter متكامل للياقة البدنية مدعوم بالذكاء الاصطناعي. يوفر التطبيق تجربة تدريب شخصية مع مدرب ذكي (Smart Coach)، خطط تمارين مخصصة، توصيات غذائية، وتتبع شامل للتقدم. التطبيق يدعم اللغتين العربية والإنجليزية بشكل كامل.

**Super Fitness** is a comprehensive Flutter-based fitness application powered by AI. The app provides a personalized training experience with an AI Smart Coach, customized workout plans, nutritional recommendations, and comprehensive progress tracking. The app fully supports both Arabic and English languages.

## 🏗️ Architecture

### Clean Architecture Pattern

The project follows **Clean Architecture** principles with clear separation of concerns:

```
lib/
├── core/                          # Core functionality
│   ├── config/
│   │   ├── routing/              # Navigation & routes
│   │   └── theme/                # App theme & colors
│   ├── di/                        # Dependency injection
│   │   └── injection.dart        # GetIt service locator
│   ├── helpers/                   # Utility helpers
│   ├── l10n/                      # Localization files
│   ├── network/                   # API client & interceptors
│   ├── components/                # Reusable UI components
│   ├── utils/                     # Constants & extensions
│   └── extensions/                # Dart extensions
├── features/                      # Feature modules
│   ├── auth/                      # Authentication
│   │   ├── data/
│   │   │   ├── datasources/      # API data sources
│   │   │   ├── models/           # Data models
│   │   │   └── repositories/     # Repository implementations
│   │   ├── domain/
│   │   │   ├── entities/         # Business entities
│   │   │   ├── repositories/     # Repository interfaces
│   │   │   └── usecases/         # Business logic
│   │   └── presentation/
│   │       ├── pages/            # UI screens

```

### Architecture Layers

1. **Presentation Layer** - UI, widgets, and state management (BLoC/Cubit)
2. **Domain Layer** - Business logic, entities, and use cases
3. **Data Layer** - Data sources, models, and repository implementations
4. **Core Layer** - Shared utilities, constants, and configurations

### Design Patterns

- **Repository Pattern** - Abstraction of data sources
- **BLoC Pattern** - State management for complex features
- **Cubit Pattern** - Lightweight state management for simple features
- **Dependency Injection** - Loose coupling and testability with GetIt
- **Use Case Pattern** - Encapsulation of business logic
- **Service Locator Pattern** - GetIt for DI container
- **Factory Pattern** - Object creation

## 🔧 Configuration

### Environment Setup

1. **Clone the repository:**
```bash
git clone https://github.com/YourUsername/super-fitness-app.git
cd super-fitness-app
```

2. **Install dependencies:**
```bash
flutter pub get
```

3. **Set up Firebase:**
   - Create a Firebase project on [Firebase Console](https://console.firebase.google.com)
   - Add Android and iOS apps to your Firebase project
   - Download configuration files:
     - `google-services.json` for Android → place in `android/app/`
     - `GoogleService-Info.plist` for iOS → place in `ios/Runner/`

4. **Configure Google Gemini AI:**
   - Get your API key from [Google AI Studio](https://makersuite.google.com/app/apikey)
   - Add to `.env` file:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

5. **Generate code:**
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

6. **Run the app:**
```bash
flutter run
```

### API Configuration

Create a `.env` file in the project root:

```env
# API Endpoints
API_BASE_URL=https://your-api-domain.com/api
API_VERSION=v1

# Google Gemini AI
GEMINI_API_KEY=your_gemini_api_key

# Firebase
FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_API_KEY=your_firebase_api_key

# App Configuration
APP_NAME=Super Fitness
APP_VERSION=1.0.0
```

### Localization

Translation files are located in `assets/translations/`:
- `en.json` - English translations
- `ar.json` - Arabic translations

